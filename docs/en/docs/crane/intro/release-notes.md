# Cockpit Release Notes

This page lists the release notes for Cockpit, providing an overview of version evolution and feature changes.

## 2026-08-31

### v0.1.0

- **Added** the first release of Cockpit, providing Token Factory operations visualization capabilities
- **Added** the Business Overview Panel (Token Factory operations center), which presents production and business metrics in a 3x3 grid
- **Added** core modules such as real-time production metrics, token flow, business revenue, and GPU resource status
- **Added** the capacity monetization funnel, revenue and gross profit trends, tenant value quadrant, consumption distribution, and top model contribution
