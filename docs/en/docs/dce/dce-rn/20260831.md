# DCE v0.44.0-20260831 Enterprise Released

This page explains the latest features, improvements and bug fixes, included
in DCE v0.44.0-20260831 Enterprise. DCE modularizes each product module,
and the versions included in this release are the default versions
in the DCE installer. If you need to independently upgrade or replace each module, contact
Daocloud's support team to download the proper versions and upgrade. Also refer to
[DCE Enterprise Deployment Requirements](../../install/commercial/deploy-requirements.md).

## Upgrade Notes

* **Hydra v0.18.3 and later** bases the MaaS enablement status and the visibility scope of
  clusters and Workspaces uniformly on the Knoway `ModelRoute` CR. When upgrading from v0.16.0 or
  v0.17.1, upgrade the `hydra-agent` on all worker clusters first, and then upgrade the global Hydra.
  For details, see [Hydra Upgrade Notes](../../hydra/intro/upgrade-notes.md).

* **GPU Addon upgrade (Container Management)**: When upgrading the `nvidia-vgpu` Addon from
  `v2.8.3` to `v2.9.0`, upgrade the following dependent components accordingly:

    * Upgrade Kpanda to `v0.48.0`
    * Upgrade Insight to `v0.42.2`
    * Upgrade Insight Agent to `v0.42.2`

    This change applies to both the **open-source and commercial editions of HAMI**.

* When **upgrading Kubernetes to v1.35 or later**, the operating system must use **cgroup v2**.
  For details, see [Installer Upgrade Notes](../../install/upgrade-notes.md).
