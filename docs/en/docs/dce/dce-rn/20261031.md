in the DCE installer. If you need to independently upgrade or replace each module, contact
Daocloud's support team to download the proper versions and upgrade. Also refer to
[Deployment Requirements](../../install/commercial/deploy-requirements.md).

## Upgrade Notes <a id="upgrade-notes" />

* **LLM Studio**: When upgrading to Hydra v0.20.0, environments using intelligent routing should
  first upgrade `hydra-agent` and the accompanying Knoway on worker clusters, and then upgrade the
  global Hydra. After the upgrade, re-save the intelligent routing configuration to avoid request
  failures caused by stale model registrations. If offline models or custom Embedding
  configurations are used, adjust the model catalog and dimensions as instructed in the guide.

* **AI Lab**: After upgrading to Baize v0.31.1, before enabling the newly added S3 TLS, custom CA,
  or NFS version options, independently upgrade the Dataset CRD, Controller, and data-loader on
  worker clusters to v0.1.16. S3 configurations that rely on legacy RCLONE TLS environment
  variables should be changed to explicit TLS/CA configurations before the upgrade.

* **Kubernetes cluster management**: The default recipe of Kubean v0.39.5 in this release
  supports Kubernetes v1.35.0 as the minimum version. Before performing installation,
  scaling, or re-run operations on clusters still specifying v1.34, prepare a compatible
  Kubean/recipe version combination, or plan a Kubernetes upgrade.
