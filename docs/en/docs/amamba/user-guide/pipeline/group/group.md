# Pipeline Groups

Pipelines can be classified by group, which makes it easier for an enterprise to manage pipelines.

## Group Management

Each workspace can create multiple pipeline groups.

1. Go to __Pipelines__ and click `Group Management`.

    ![group1](../../../images/group1.jpg)

2. Enter a group name in the Group Management page to create a group.

    ![group2](../../../images/group2.jpg)

3. You can also delete a group. After the group is deleted, pipelines in the group also lose their group.

    ![group3](../../../images/group3.jpg)
