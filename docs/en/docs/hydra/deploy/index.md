# Model Serving

*[Hydra]: Internal codename for LLM Studio

Model Serving allows you to quickly deploy open-source, self-developed, or fine-tuned large language models
as inference services that can be called within the platform.

- Users can call the selected model service to perform tasks such as text generation, image understanding, and image generation.
- Online model trials are supported.
- API calls and service O&M management are supported.
