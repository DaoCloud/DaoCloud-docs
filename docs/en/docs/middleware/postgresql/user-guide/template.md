# Parameter Template

DCE PostgreSQL provides a parameter template feature to facilitate instance creation.

1. On the PostgreSQL database page, click **Parameter Template** in the left navigation bar.

    ![Parameter Template](../images/template01.png)

2. Click the name of a parameter to view all the parameters contained in the template.

    ![Parameter Template](../images/template02.png)

3. You can import and export parameter templates in the UI.

    ![Parameter Template](../images/template03.png)
