# Intro

[kgateway](https://github.com/kgateway-dev/kgateway) is a high-performance, cloud native API gateway
built on the Envoy proxy with deep integration of the Kubernetes Gateway API. It aims to provide a
next-generation control plane for AI inference, microservice governance, and cross-cluster traffic scheduling.
