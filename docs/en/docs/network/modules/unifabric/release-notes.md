# Unifabric Release Notes

## 2025-11-05

### v0.1.0

- **Added** Hierarchical topology display, supporting the connection architecture of Spine and Leaf switches, super node groups, and storage devices.
- **Added** Connection status indication, supporting real-time display of the connection status between devices. The link automatically disappears when the connection is interrupted.
- **Added** Spine/Leaf switch monitoring, supporting the display of switch running data and monitoring metrics.
- **Added** Compute node monitoring, supporting the display of compute node status and performance information.
- **Added** Storage device display, supporting the display of the connection status of storage devices.
- **Added** Compute switch list, supporting the display of switch role, management IP, port status, TX bandwidth, utilization, and startup time.
- **Added** Storage switch list, supporting the display of management IP, port status, TX bandwidth, and utilization.
- **Added** Node list, supporting the display of basic node information, RDMA count, Pod count, and bandwidth utilization.
- **Added** Topology navigation, supporting clicking a super node area to view the internal topology view of the corresponding super node group.
- **Added** Cluster switching, supporting display switching across multiple clusters.
- **Added** Super node switching, supporting switching the super node group view.
- **Added** Super node group view, supporting the display of the internal interconnection structure of a specified super node group.
- **Added** Node status display, supporting the display of node health status.
- **Added** GPU interconnection details, supporting the display of GPU link connections between different super nodes.
- **Added** Link performance analysis, supporting clicking any link path to view real-time link performance metrics.
- **Added** Link list view, supporting the display of link node name, GPU device ID, link ID, RX/TX rate, network error (UE), and congestion (CE).
