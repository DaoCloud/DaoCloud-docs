# Intro

[Higress](https://github.com/alibaba/higress) is a cloud native API gateway built on Envoy that deeply
integrates Nacos service discovery and Sentinel rate limiting. It follows the Kubernetes Gateway API
standard and is compatible with Kubernetes Ingress gateways, aiming to deliver a high-performance
distribution and governance solution that combines a traffic gateway, a microservice gateway,
and a security gateway.
