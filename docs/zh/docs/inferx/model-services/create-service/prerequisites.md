# 部署前准备

本文介绍使用推理加速服务部署模型服务前需要准备的环境、资源和模型文件。首次部署建议先完成本页检查，再选择对应的部署实践。

## 准备环境

- 用户权限：具有目标工作空间、集群和命名空间的访问及部署权限。

- 计算资源：GPU 型号、卡数、显存、CPU 和内存配额满足部署方案需求。

- 推理镜像：镜像支持目标模型和硬件。如需使用自定义镜像，请确保节点可以访问目标镜像仓库。

- 模型权重 ：上传模型权重到目标集群命名空间下可用的 PVC 中。

- 网络资源：PD 分离和跨节点部署所需网络已配置。需要 RDMA 时，已在目标集群配置所需网络资源。

- 部署模板（可选）：与目标模型和 GPU 资源相匹配、经验证的部署模板，用于快速部署。

## 可选部署方式

- 优选模板：已有匹配模型、硬件和推理模式的已验证模板，只需补充环境信息即可部署。

- 通用模板：需要按现场模型、硬件和推理引擎配置资源及推理参数。

- 自定义部署：已有与当前平台 Chart 模板匹配的 values.yaml，直接填写配置部署。

建议优先使用 **优选模板** 。平台预置了丰富的部署模板库，标记为“生产可用”的模板已通过真实环境验证；标记为“抢先体验”的模板适合试用和评估。

若没有完全匹配目标模型与硬件组合的优选模板，可参考相近模板，将其参数复制到 **通用模板** 中，按需调整后部署。例如，部署 GLM-5.3 时，可参考相同硬件下的 GLM-5.2 优选模板，调整模型相关的推理参数，并验证兼容性与运行效果。
