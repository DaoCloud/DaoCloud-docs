# 部署前准备

本文介绍部署模型服务前需要准备的环境、资源和模型文件。完成检查后，选择与目标模型及硬件匹配的部署方式。

## 准备环境

- **用户权限**：确认具备目标工作空间、集群和命名空间的访问及部署权限。参见 [工作空间权限说明](../../../ghippo/user-guide/workspace/ws-permission.md)。
- **系统组件**：确认目标集群已安装推理加速服务所需的系统组件。
- **计算资源**：确认 GPU 型号、卡数、显存、CPU 和内存资源与配额满足部署方案。
- **推理镜像**：选择支持目标模型和硬件的镜像。如使用自定义镜像，确认目标节点能够拉取镜像。
- **模型权重**：将模型权重存放到目标集群和命名空间中可用的 PVC。参见 [模型权重下载与配置](../../guides/model-weights-setup.md)。
- **网络资源**：PD 分离和跨节点部署前，确认节点间网络可用。部署方案要求 RDMA 时，提前配置对应网络资源。
- **部署模板（可选）**：使用优选模板时，确认模板库中有适配目标模型和 GPU 的模板。

## 可选部署方式

- [优选模板](optimized-template.md)：选用与模型、GPU 和推理模式匹配的模板，补充部署环境信息。
- [通用模板](generic-template.md)：根据模型、硬件和推理引擎，自行配置资源和推理参数。
- **自定义部署**：使用与当前平台 Helm Chart 匹配的 `values.yaml` 部署。

选择合适的优选模板可用于快速部署。标记为 **生产可用** 的模板表示已通过真实环境验证，标记为 **抢先体验** 的模板表示适合试用和评估。

没有完全匹配的模板时，可将相近模板的参数复制到 **通用模板** 中，按实际模型、硬件和引擎调整后，验证兼容性及运行效果。
