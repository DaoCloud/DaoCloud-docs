# Token 工厂文档

Token 工厂是 DaoCloud 面向 AI 智算场景打造的一体化平台，围绕大模型推理、算力调度和集群运维提供端到端的能力支撑。

平台深度整合了大模型服务平台与 InferX 推理引擎，向上承接模型部署与推理加速，向下依托容器管理实现 GPU 算力的精细化调度与资源编排。同时，通过可观测性模块对推理性能、算力利用率和基础设施健康度进行全方位监控，配合全局管理完成用户权限、工作空间和审计日志的统一治理，构建起从算力接入到模型服务的完整闭环。

## 核心能力

- **大模型服务平台**：提供模型托管、版本管理和在线推理服务，支持多种主流大模型的快速部署与弹性扩缩容。
- **InferX 推理引擎**：针对 GPU 推理场景深度优化，通过算子融合、动态批处理和显存复用等技术显著提升推理吞吐量，降低单次推理延迟。
- **容器管理**：基于 Kubernetes 提供 GPU 资源池化、多租户隔离和优先级调度，实现算力资源的高效分配与回收。
- **可观测性**：覆盖集群、节点、容器和应用的多维度监控，提供指标采集、日志检索和链路追踪能力，帮助快速定位推理瓶颈与系统异常。
- **全局管理**：统一管理用户与访问控制、工作空间层级、审计日志和运营报表，保障平台的安全合规与资源可追溯。
