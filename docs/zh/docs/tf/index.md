# Token 工厂

Token 工厂是 DaoCloud 面向 AI 智算场景打造的一体化平台，围绕大模型推理、算力调度和集群运维提供端到端的能力支撑。

平台深度整合了大模型服务平台与 InferX 推理引擎，向上承接模型部署与推理加速，向下依托容器管理实现 GPU 算力的精细化调度与资源编排。同时，通过可观测性模块对推理性能、算力利用率和基础设施健康度进行全方位监控，配合全局管理完成用户权限、工作空间和审计日志的统一治理，构建起从算力接入到模型服务的完整闭环。

![Token 工厂运营中心](./images/tf01.png)

Token 工厂运营中心是 AI 时代的智能生产驾驶舱，将 Token 生产全链路转化为可量化、可追踪、可优化的实时数据视图，让运营团队对平台的每一秒运转都了如指掌。驾驶舱以毫秒级数据刷新呈现平台实时运转状态。

## 模块导航

- [大模型服务平台](hydra/intro/index.md)：提供模型托管、版本管理和在线推理服务，支持多种主流大模型的快速部署与弹性扩缩容。
- [InferX 推理引擎](inferx/intro/index.md)：针对 GPU 推理场景深度优化，通过算子融合、动态批处理和显存复用等技术显著提升推理吞吐量，降低单次推理延迟。
- [容器管理](kpanda/intro/index.md)：基于 Kubernetes 提供 GPU 资源池化、多租户隔离和优先级调度，实现算力资源的高效分配与回收。
- [可观测性](insight/intro/index.md)：覆盖集群、节点、容器和应用的多维度监控，提供指标采集、日志检索和链路追踪能力，帮助快速定位推理瓶颈与系统异常。
- [全局管理](ghippo/intro/index.md)：管理用户权限、多租户、账号、审计日志等。
