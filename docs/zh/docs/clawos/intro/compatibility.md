# 兼容性

本页列出 ClawOS 智能体与 Kubernetes 集群的兼容性测试结果，帮助您选择合适的集群版本。

✅：测试通过；❌：测试未通过或不支持；空：未进行测试。

| 场景 | 测试方式 | K8s 1.37.0 | K8s 1.36.1 | K8s 1.35.0 | K8s 1.33.0 | K8s 1.31.0 | K8s 1.29.4 | K8s 1.27.16 | K8s 1.25.16 | K8s 1.23.17 |

!!! note

    **测试说明：**

    1. 兼容性测试基于 AgentClaw E2E 用例，使用 kind 集群依次验证上述 Kubernetes 版本，测试范围为冒烟（smoke）用例。
    2. 网络策略流量管控依赖集群 CNI 对 NetworkPolicy 的实现。在 K8s 1.2x（v1.23、v1.25、v1.27、v1.29）的 kind 环境中，默认 CNI（kindnet）不支持 NetworkPolicy，因此该场景在这些版本上不支持；网络策略模板管理功能不受影响。
    3. 生产环境如需使用网络策略流量管控，请确保集群 CNI 支持 NetworkPolicy，并建议使用 K8s 1.31.0 及以上版本。

    **支持的 Kubernetes 版本：** v1.23.17、v1.25.16、v1.27.16、v1.29.4、v1.31.0、v1.33.0、v1.35.0、v1.36.1、v1.37.0。
