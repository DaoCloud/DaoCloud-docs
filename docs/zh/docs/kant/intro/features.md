# 功能特性

云边协同将云原生能力延伸至边缘，采用 “端-边-云” 一体化协同架构，帮助企业快速拓展安全、灵活、高效、可靠的边缘云原生能力，
广泛适用于工业互联网、物联网、智慧工厂、智慧园区、智慧零售等领域。云端实现边缘节点的注册、管理及应用和配置的下发，
边缘侧负责运行边缘应用，实现边缘自治，设备侧支持多协议终端接入，并提供标准接口对接设备能力。

云边协同支持以下功能特性：

| 功能特性 | 说明 |
| --- | --- |
| **边缘节点管理** | 支持海量边缘节点接入并自动生成节点配置；提供 Token、证书两种纳管方式；可在云端统一管理、监控和运维节点。 |
| **边缘应用/模型管理** | 将应用或模型打包为容器镜像，上传镜像仓库后快速部署到边缘节点运行；支持查看实例的运行数据、事件与日志；容器生态带来更好的可移植性与资源隔离，并支持 CPU / GPU 调度。 |
| **边缘设备管理** | 支持终端通过多种协议接入边缘节点；接入后可在云端统一管理终端设备。 |
| **应用网格** | 通过服务发现与流量代理实现边缘业务流量闭环，解决边缘场景下边缘业务之间的通信问题。 |
| **数据管理** | 提供消息路由功能，可配置路由规则；平台按规则将边缘消息转发至对应消息端点，灵活控制数据路由并提升数据安全性。 |
| **权限管理** | 采用平台 / 文件夹 / 工作空间三级权限，可按业务需求精细化配置，保障资源的安全与共享；内置多种角色且权限范围可按需调整；分配角色时按「确定业务需求 → 选择角色 → 配置权限」流程执行，并遵循最小权限原则。 |
| **边缘控制** | 提供边缘节点的资源调度与管理运维、应用与模型的全生命周期管理；支持数据采集与设备协议转换，可采集边缘节点关联设备的数据；提供 EventBus → 云端 REST、云端 REST → 边缘 EventBus / ServiceBus 等消息转发路径，并支持图片、视频、文件等非结构化数据的云边双向传输。 |
