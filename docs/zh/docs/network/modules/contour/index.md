# 什么是 Contour

Contour 是一个开源的 Kubernetes Ingress 控制器，使用 Envoy 作为数据面。
Contour 支持动态配置更新和开箱即用的多团队入口代理，同时保持轻量级配置文件。

## Contour vs Nginx Ingress

- 数据面与控制面分离
- 管理方便
- 性能优势
- 更易于使用的声明式语法
- 更全面的监控指标
- Gateway API 的支持
