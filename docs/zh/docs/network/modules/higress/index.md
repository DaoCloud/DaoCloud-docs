# 介绍

[Higress](https://github.com/alibaba/higress) 是一个以 Envoy 为核心并深度集成 Nacos 服务发现与 Sentinel 限流能力的云原生 API 网关，遵循 Kubernetes Gateway API 标准并兼容 Kubernetes Ingress 网关，旨在提供集流量网关、微服务网关、安全网关于一体的高性能分发与治理方案。
