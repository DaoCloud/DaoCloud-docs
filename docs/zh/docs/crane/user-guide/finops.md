# 财务运营

财务运营（FinOps）页面主要面向企业财务运营人员，汇总所选财务周期内的收入、成本、预算和资产回报信息，帮助评估算力投入与经营表现。页面内容会根据部署模式调整：运营模式（CSP）展示对外服务的收入与资产经营分析；企业模式（WS）侧重成本、预算和内部成本分摊。

## 如何打开

1. 登录 Token 工厂控制台。
2. 在产品导航中打开 **驾驶舱**，选择 **财务运营** 菜单。

![财务运营页面](../images/crane-02.png)

## 筛选财务数据

页面顶部提供两个筛选条件：

- **财务周期**：本月、上月、本季度或本年度。切换周期后，相关 KPI、成本结构、趋势和资产分析会按新周期更新。
- **核算范围**：合并、外部收入或内部核算。用于选择财务数据的核算口径。

金额和资产指标受上游账单、成本及资产数据影响。页面请求失败时会显示异常状态；

## 运营模式（CSP）

页面 KPI 包含周期收入、成本、毛利和预算剩余；单位 Token 成本、收入、利润与成本回收率；以及资产机器数、平均单机收入、平均单机利润和预计加权回本期。

其他分析面板包括：

- **机器资产排行**：查看机器、区域、配置、Token 用量、收入、运行成本、折旧、利润率和回本期。列表可翻页。
- **资产回报矩阵**：对比资产投入与经营表现，定位回报较高或需要关注的资产。
- **成本结构分析**：查看成本构成及各项占比。
- **收入与成本趋势**：观察所选财务周期的收入和成本变化。
- **扩容影响试算**：比较扩容方案对预算、收入、利润和回收周期的预估影响。
- **FinOps 优化建议**：根据当前经营情况提供优化参考。

## 企业模式（WS）

页面展示周期成本、预算剩余、单位 Token 成本和资产机器数，收入和利润类对外经营 KPI 不在此模式显示。

成本结构分析帮助定位主要成本项；成本分摊摘要按组织或业务对象查看 Token 用量、分摊成本、收入贡献与 ROI；预算预测用于观察预算使用趋势；FinOps 优化建议提供成本治理参考。

## 理解常用指标

| 指标 | 含义 |
| --- | --- |
| 毛利 | 收入减去经营成本 |
| 预算剩余 | 当前周期预算扣除已使用预算后的剩余金额，最低按 0 计 |
| 单位 Token 成本、收入、利润 | 将周期成本、收入或利润按 Token 用量折算为每百万 Token 的金额 |
| 成本回收率 | 周期收入相对周期成本的比例 |
| 平均单机收入、利润 | 周期收入或毛利按可资产化机器数计算的平均值 |
| 预计加权回本期 | 按资产价值加权估算的投入回收周期 |

不同核算范围会影响收入和成本的归集结果。比较周期或资产表现时，请保持财务周期与核算范围一致；缺少账单、成本或资产记录时，相关指标可能显示为空或不可用。
