# 经营价值

经营价值页面主要面向企业管理者，用于查看平台产能、Token 产出、收入与客户或部门使用情况。页面按部署模式展示不同内容：运营模式（CSP）关注对外服务的经营收益与客户结构；企业模式（WS）关注内部部门用量和产能。

## 如何打开

1. 登录 Token 工厂控制台。
2. 在产品导航中打开 **驾驶舱**，选择 **经营价值** 菜单。

![经营价值页面](../images/crane-01.png)

页面 KPI 与常规面板约每分钟刷新一次。使用页面顶部的时间范围筛选，可查看今日、本周、本月或本季度的数据。切换范围后，适用该筛选的指标和图表会更新；实时吞吐及部分趋势分析使用各自固定的统计窗口。

## 页面指标

**面向角色：**平台运营、业务负责人及需要了解指标含义的用户。

### 核心指标

| 指标 | 说明 | 适用模式 |
| --- | --- | --- |
| 实时吞吐 | 最近 10 分钟的平均 Token 生产速率，按每分钟展示。 | 运营、企业 |
| 额定产能 | 所选范围内平台的额定 Token 生产能力，用于对比当前吞吐。 | 运营、企业 |
| 产能利用率 | 实时吞吐相对于额定产能的比例。 | 运营、企业 |
| 注册用户 | 所选自然周期内的注册用户数，并提供周期对比。 | 运营 |
| 活跃模型 | 所选周期内有调用记录的去重模型数，并展示其当前在线和离线数量。 | 运营、企业 |
| 累计产出 | 所选周期内累计生产的 Token 数量，可查看历史趋势。 | 运营、企业 |
| 收入 | 所选周期的收入，并与上一周期同进度比较。 | 运营 |
| 毛利 | 收入减去成本；页面同时展示毛利率及周期对比。 | 运营 |
| ROI 投资回报率 | 用于衡量投入与回报的关系，辅助评估经营表现。 | 运营 |
| 容量瓶颈预警 | 展示产能瓶颈预测，辅助识别容量风险。 | 企业；运营模式在预测区域展示 |

### 分析面板

| 面板 | 说明 | 适用模式 |
| --- | --- | --- |
| 月末预测 | 根据已有数据预测月末收入和毛利；数据不足时显示占位。 | 运营 |
| 产能变现漏斗 | 查看可供给、已调度、有效计费、高毛利和未变现等环节的 Token 规模。 | 运营 |
| 客户消费分布与集中度 | 查看客户用量排行和占比，以及 Top1、Top3、Top5 和长尾集中度风险。 | 运营 |
| 部门用量与集中度 | 查看部门 Token 用量排行，以及部门用量集中度和风险等级。 | 企业 |
| 模型贡献 | 查看不同模型对平台业务的贡献排行。 | 运营 |
| 租户价值四象限与增长趋势 | 按 Token 消耗和收入观察客户分布，并查看近期租户增长趋势。 | 运营 |
| 平台收入趋势与收入来源 | 查看平台收入的变化及来源构成。 | 运营 |
| 余额与代金券概览、新增用户趋势 | 查看余额、充值和代金券情况，以及新增用户变化。 | 运营 |
| 健康摘要与经营建议 | 汇总平台健康状态、风险识别和经营建议。 | 运营、企业 |

不同面板可能使用固定窗口，不一定跟随页面顶部时间筛选；比较指标时请留意面板显示的统计范围。

## 运营模式（CSP）

**面向角色：**对外 MaaS 服务的业务负责人、商业运营和财务分析人员。

页面顶部展示实时吞吐、额定产能、产能利用率、注册用户、活跃模型、累计产出、收入、毛利和 ROI。产能利用率用于观察当前吞吐相对额定产能的情况；收入与毛利卡片提供周期对比，ROI 用于辅助评估投入回报。部分卡片可打开历史趋势，查看所选范围内的变化。

页面下方还提供月末收入和毛利预测、产能瓶颈预警、产能变现漏斗、按客户的消费分布及集中度分析、收入与毛利趋势及预测、模型贡献等内容。客户集中度根据客户 Token 消耗计算 Top1、Top3、Top5 和长尾占比，并按页面给出的风险等级识别客户依赖情况。租户价值四象限结合 Token 消耗和收入贡献观察客户分布；租户增长趋势展示近期增长较快的客户。

平台收入分析展示收入趋势与来源构成；余额与代金券概览展示余额、充值和代金券情况；新增用户趋势展示近期新增用户变化。风险识别与经营建议帮助发现经营指标中的异常和可采取的改进措施。

## 企业模式（WS）

**面向角色：**企业 AI 平台负责人、部门管理员和内部运营人员。

页面顶部展示实时吞吐、额定产能、产能利用率、活跃模型、容量瓶颈预警和累计产出。注册用户、收入、毛利和 ROI 等外部经营指标不适用于此模式。

部门 Token 用量排行和部门集中度分析用于了解组织内的用量分布。排行展示主要部门；集中度分析按全部有效部门的用量计算 Top1、Top3、Top5 和长尾占比。容量瓶颈、风险识别与经营建议提供产能和运营方面的参考。

## 查看指标时的注意事项

**面向角色：**使用指标开展分析、对账或排查数据问题的人员。

- **实时吞吐**是近期请求和 Token 用量的平均速率，适合观察当前生产态势；累计产出展示所选周期内的 Token 总量。
- **收入、成本和毛利**依赖账单和用量数据。经营收益相关数据通常会按服务配置的本地账期统计，时间边界可能与浏览器所在时区不同。
- **预测**是依据已有历史数据生成的趋势参考。历史数据不足时，预测可能不可用或以占位状态显示。
- **部门配额与用量**依赖工作区配额及实际调用记录；未配置配额或没有调用数据时，相关模块可能没有可展示的数据。
- **客户或部门集中度**按当前筛选范围计算；分布总量与排行数据不完整时，应先排查上游用量数据。
