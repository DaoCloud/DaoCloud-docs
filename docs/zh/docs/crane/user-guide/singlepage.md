# 经营概览面板

经营概览面板是驾驶舱的默认入口，以固定 **九宫格** 展示 Token 生产与经营全貌。

页头右上角显示本地实时时间与「运行中」状态；业务数据默认约每分钟刷新一次。

![经营概览面板](../images/singlepage.png)

## 如何打开

1. 进入 Token 工厂控制台。
2. 打开产品导航中的 **驾驶舱**。
3. 选择 **经营概览**（默认入口）。

## 页面说明

| 区域 | 说明 |
| --- | --- |
| 页头 | 本地时间、「运行中」状态 |
| 九宫格 | 实时生产、流量、经营/组织、GPU、结构与模型贡献等模块 |
| 面板状态 | 首次加载显示「加载中」；请求失败显示「系统异常」，不展示过期错误明细 |

单个模块失败不会阻塞其他模块展示。

## 九宫格模块

=== "运营模式"

    | 模块 | 看什么 |
    | --- | --- |
    | **实时生产指标** | 实时吞吐、今日累计产出、Token 延迟（P90）；第 4 卡为 **SLA 达标率**（相对目标的百分点差） |
    | **实时 Token 流动** | 平台 Token 流量与环比变化 |
    | **经营收益** | 今日收入、成本、毛利及单位 Token 成本（`/ M Token`） |
    | **GPU 资源状态** | GPU 池运行态势与异常资源 |
    | **产能变现漏斗** | 从产能到计费 Token 的转化过程 |
    | **收入与毛利趋势及预测** | 收入 / 毛利历史走势与预测 |
    | **高消耗 × 高价值四象限** | 租户 Token 消耗与收入贡献的象限分布 |
    | **消费分布** | 按客户的用量分布，以及客户集中度风险分级 |
    | **热门模型贡献** | 模型维度的贡献排行 |

=== "企业模式"

    | 模块 | 看什么 |
    | --- | --- |
    | **实时生产指标** | 实时吞吐、今日累计产出、Token 延迟（P90）；第 4 卡为 **实时请求数**（req/m） |
    | **实时 Token 流动** | 平台 Token 流量与环比变化 |
    | **本期经营概览** | 本月活跃用户覆盖、调用量对比、成本分摊与近 7 日用户趋势 |
    | **GPU 资源状态** | GPU 池运行态势与异常资源 |
    | **部门配额与消耗** | 组织月配额、本月消耗、剩余配额；有限配额使用率 ≥ 80% 计入预警 |
    | **用量与容量趋势** | 近 30 日输入 / 输出 Token 与 GPU 利用率，并附 7 日预测虚线 |
    | **高消耗 × 高价值四象限** | 部门 Token 消耗与活跃用户数的象限分布 |
    | **组织使用分布** | 按部门的用量分布，以及部门集中度风险分级 |
    | **热门模型贡献** | 模型维度的贡献排行 |

## 阅读建议

- **运营模式经营复盘**：结合经营收益、产能变现漏斗、收入毛利趋势与客户集中度，判断收入质量与客户结构风险。
- **企业模式组织治理**：结合本期经营概览、部门配额与组织使用分布，识别超额部门与低效象限。

## 常见问题

**为什么部分模块没有数据？**

驾驶舱为读侧聚合视图，依赖用量、账单、GPU 指标等上游数据。若对应集群或账期尚无数据，模块会显示「暂无数据」或保持加载失败态，可先确认模型服务是否在产生调用、费用与可观测链路是否正常。
