# 驾驶舱 Release Notes

本页列出驾驶舱的 Release Notes，便于您了解各版本的演进路径和特性变化。

## 2026-09-30

### v0.5.3

- **新增** 经营价值面板，从产能、活跃模型和部门 Token 用量看内部 AI 使用情况
- **新增** 财务运营面板，从成本、预算剩余、单位 Token 成本和成本分摊看内部算力花费
- **新增** 生产运营面板，实时查看吞吐、延迟、队列、热点模型和 GPU 状态
- **新增** 风险防护面板，识别内部 Token 使用中的风险入口和拦截情况，覆盖 Agent 保护、输出安全与安全事件审计。

## 2026-08-31

### v0.2.0

- **新增** 总览大屏，查看实时生产与请求量、Token 流动、本期经营概览、GPU 资源、部门配额，以及部门用量和容量趋势。
