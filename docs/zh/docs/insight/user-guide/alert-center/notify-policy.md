# 通知策略

通知策略用于定义告警触发后如何向指定对象发送消息。通过通知策略，您可以按告警级别、标签等条件匹配告警，并指定通知对象、消息模板和发送间隔。

通知对象需预先在 [通知配置](message.md) 中添加；消息内容可通过 [消息模板](msg-template.md) 自定义。

## 创建通知策略

1. 在左侧导航栏中，选择 __告警中心__ -> __通知策略__，点击 __新建通知策略__ 按钮。

2. 填写通知策略的各项参数后，点击 __确定__。

    | 参数 | 说明 |
    | ---- | ---- |
    | 名称 | 通知策略名称。 |
    | 描述 | 通知策略的描述信息。 |
    | 匹配条件 | 按告警级别、标签等条件匹配需要通知的告警。 |
    | 通知对象 | 接收告警消息的对象，支持邮件、企业微信、钉钉、飞书、Webhook、短信和站内信。 |
    | 消息模板 | 发送通知时使用的消息模板。 |

3. 返回通知策略列表，可查看已创建的通知策略。

## 编辑通知策略

在列表右侧点击 __┇__，选择 __编辑__，可以修改通知策略。

## 删除通知策略

在列表右侧点击 __┇__，选择 __删除__。

!!! warning

    删除后的通知策略将无法恢复，请谨慎操作。
