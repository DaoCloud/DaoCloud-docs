# 兼容性

本页列出 Token 工厂 Copilot 智能体与 Kubernetes 集群的兼容性测试结果，帮助您选择合适的集群版本。

✅：测试通过；❌：测试未通过或不支持；空：未进行测试。

!!! note

    **测试说明：**

    1. 兼容性测试基于 Copilot kind E2E 用例，CI 定时流水线按 Kubernetes 版本通过矩阵任务并行执行：每个版本创建独立的一次性 kind 集群，安装本次流水线构建的镜像与 Chart，测试范围为冒烟（smoke）用例，覆盖安装、存活与基本能力。
    2. 每个版本的任务在创建集群前还会执行安装表单契约的静态校验（`helm template` + `yq`），该部分与集群版本无关，任一版本失败即视为不通过。
    3. 安装表单的扩展场景（内联密钥、dceAuth、PVC 持久化 + Recreate、clientConfig 交付）不在兼容性测试范围内执行，由常规的 kind E2E 流水线覆盖。
    4. 测试使用 kind v0.33.0 及以上版本。旧版 kind 生成的 `kubeadm.k8s.io/v1beta3` 配置在 K8s 1.37.0 及以上不再被接受，且无法向 containerd 2.x 节点加载镜像。
    5. 测试全程使用集群内的 mock 模型与假 token，不覆盖真实模型服务和真实 DCE 登录；kind 环境中关闭了 NetworkPolicy 与平台网关子路径，相关能力由静态用例和 UI 自动化覆盖。
    6. 生产环境请结合实际使用的 CNI、存储与网关能力选择集群版本，并确认对应 Kubernetes 版本仍处于维护周期内。

    **支持的 Kubernetes 版本：** v1.23.17、v1.25.16、v1.27.16、v1.29.4、v1.33.0、v1.35.0、v1.36.1、v1.37.0。
