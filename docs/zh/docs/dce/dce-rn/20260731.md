# DCE v0.43.0-20260731 商业版正式发布

本页说明了 DCE v0.43.0-20260731 商业版包含的最新特性、优化、缺陷修复等。
DCE 每个产品模块都是独立解耦的，本次发布中所涉及的产品模块为 DCE 安装器默认包含的版本。
如需独立升级或替换各个模块，请联系 Daocloud 售后支持人员下载对应版本并升级。
另请参阅[商业版部署要求](../../install/commercial/deploy-requirements.md)。

## 升级注意事项 <a id="upgrade-notes" />

- **ClawOS v0.5.0** 调整了部分 OpenClaw 接口。升级时，请同步升级前端和后端，并确保两者版本保持一致。
  详情参见 [ClawOS 升级注意事项](../../clawos/intro/upgrade-notes.md)。

- **Insight v0.43.1** 升级了 Grafana Operator 组件版本，并调整了镜像地址的配置方式。升级时，
  需按照新的配置方式分别指定镜像仓库地址和镜像名称，否则可能导致组件拉取镜像失败。详情参见
  [Insight 升级注意事项](../../insight/quickstart/install/upgrade-note.md)。

- **Hydra v0.17.1 及更高版本** 将模型元数据与 MaaS 数据解耦。升级前，请先完成 `maas_model` 数据表迁移。
  详情参见 [Hydra 升级注意事项](../../hydra/intro/upgrade-notes.md)。

- **GPU Addon 升级（容器管理）**：将 `nvidia-vgpu` Addon 从 `v2.8.3` 升级至 `v2.9.0` 时，需同步升级相关依赖组件：

    * Kpanda 升级至 `v0.48.0`
    * Insight 升级至 `v0.42.2`
    * Insight Agent 升级至 `v0.42.2`

    以上变更同时适用于 **HAMI 开源版和商业版**。

- **Kubernetes 升级至 v1.35 及更高版本** 时，操作系统必须采用 **cgroup v2**。
  详情参见[安装器升级注意事项](../../install/upgrade-notes.md)。
