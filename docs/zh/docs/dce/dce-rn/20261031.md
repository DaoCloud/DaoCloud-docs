## 升级注意事项 <a id="upgrade-notes" />

- 大模型服务平台：升级到 Hydra v0.20.0 时，使用智能路由的环境应先升级工作集群的 hydra-agent 及配套 Knoway，再升级全局 Hydra。
  升级后需重新保存智能路由配置，避免旧模型登记导致请求失败；使用离线模型或自定义 Embedding 配置时，还需按指南调整模型目录和维度。
- AI Lab：升级到 Baize v0.31.1 后，启用新增 S3 TLS、自定义 CA 或 NFS 版本选项前，需独立升级工作集群的 Dataset CRD、
  Controller 和 data-loader 至 v0.1.16。依赖旧 RCLONE TLS 环境变量的 S3 配置，应在升级前改为显式 TLS/CA 配置。
- Kubernetes 集群管理：本版 Kubean v0.39.5 默认 recipe 最低支持 Kubernetes v1.35.0。
  对仍指定 v1.34 的集群执行安装、扩缩容或重跑等操作前，需准备兼容的 Kubean/recipe 版本组合，或规划 Kubernetes 升级。
