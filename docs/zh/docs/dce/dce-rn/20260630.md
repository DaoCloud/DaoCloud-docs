# DCE v0.42.0-20260630 商业版正式发布

本页说明了 DCE v0.42.0-20260630 商业版包含的最新特性、优化、缺陷修复等。
DCE 每个产品模块都是独立解耦的，本次发布中所涉及的产品模块为 DCE 安装器默认包含的版本。
如需独立升级或替换各个模块，请联系 Daocloud 售后支持人员下载对应版本并升级。
另请参阅[商业版部署要求](../../install/commercial/deploy-requirements.md)。

## 升级注意事项 <a id="upgrade-notes" />

GPU Addon 升级（容器管理）：将 nvidia-vgpu addon 从 v2.8.3 升级至 v2.9.0 时，依赖组件版本需同步进行升级，其中包括：

- 容器管理（Kpanda）升级至 v0.48.0
- Insight Server 升级至 v0.42.2
- Insight Agent 升级至 v0.42.2

该变更同时适用于 HAMi 开源版与商业版。

Kubernetes 升级到 v1.35 及更高版本，操作系统请采用 cgroup v2，详情参见[安装器升级注意事项](../../install/upgrade-notes.md)。
